

📌 Project Overview

This project builds a machine learning model to predict Formula 1 lap times based on race, driver, and circuit data. The model uses time-series features (previous lap times, pit stop indicators) and multiple regression models to optimize accuracy. It also provides real-time user input predictions formatted as MM:SS.mmm.

🚀 Features

✅ Predicts lap times using Random Forest, Gradient Boosting, and Linear Regression

✅ Uses lag-based features to capture performance trends

✅ Identifies pit stops and pit exits for better accuracy

✅ Accepts user input and returns lap time in MM:SS.mmm format


📊 Tech Stack

Python

Scikit-Learn (Machine Learning)

Pandas, NumPy (Data Preprocessing)

Matplotlib, Seaborn (Data Visualization)
